# CloudPainter — animated paintings

The published pieces, and nothing else. This repository exists **only** so that
GitHub Pages can serve them:

- **https://shibboleth88.github.io/cloudpainter-pieces/**

Two files and a landing page. Each piece is one self-contained HTML file —
canvas renderer, no dependencies, no external references, every image inlined.
Open one directly and it works; there is nothing to build here.

| | |
| --- | --- |
| `lulz.html` | the 30-second progression |
| `lulz-11s.html` | the same piece at 11 seconds |

Press `d` for an fps and phase readout, `space` to pause, arrows to scrub.

## This is a mirror, not the project

The work lives in a **private** repository — the builder, the artist's plot
layers, the master photograph, the version snapshots and the handoff document.
None of that is here, and nothing here should be edited: these files are build
outputs and any change would be overwritten by the next publish.

Published with `tools/publish.sh` from the private repository.
