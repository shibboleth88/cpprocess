# CloudPainter — process

The published pieces, and nothing else. This repository exists only
so GitHub Pages has something public to serve.

**https://shibboleth88.github.io/cpprocess/**

## Animated paintings

The artist's plotted paintings, moving the way the perception engine's visuals move. Each is one self-contained file: a progression that starts on bare copper and ends on the finished physical painting.

- [lulz — 30 seconds](https://shibboleth88.github.io/cpprocess/lulz.html) — the full progression · press d for a readout, space to pause, arrows to scrub
- [lulz — 22 seconds](https://shibboleth88.github.io/cpprocess/lulz-22s.html) — the same piece, a little tighter
- [lulz — 15 seconds](https://shibboleth88.github.io/cpprocess/lulz-15s.html) — the same piece, tighter still
- [lulz — 11 seconds](https://shibboleth88.github.io/cpprocess/lulz-11s.html) — the same piece, compressed

## The perception engine

The live piece the paintings borrow their motion from — a system perceiving a landscape and drawing what it sees. Reference, not product: it runs continuously and rations its own elements, so give it a minute before deciding nothing is happening.

- [Perception engine](https://shibboleth88.github.io/cpprocess/perception-engine.html) — the whole engine, running · this is what the paintings are imitating
- [Plotter bay](https://shibboleth88.github.io/cpprocess/plotter-bay.html) — the plotting surface
- [Internal health](https://shibboleth88.github.io/cpprocess/internal-health.html) — the engine's own readouts
- [External stimuli](https://shibboleth88.github.io/cpprocess/external-stimuli.html) — what the engine is being fed

## This is a mirror, not the project

The work lives in a private repository — the builder, the artist's
plot layers, the master photograph, the version snapshots and the
handoff. None of that is here.
